## Rincian Perbaikan Temuan (1 s/d 20)

### Kelompok 1: Prioritas TINGGI (Hard Gate & Bottleneck Performa)

1. **[R-02] Eliminasi Karakter Em Dash (`—`)**
   - *Tindakan:* Menghapus seluruh karakter em dash pada teks UI antarmuka (`src/app/page.tsx`, `src/components/events/EventPdfModal.tsx`). Diganti dengan tanda baca yang natural (koma, titik dua, atau tanda kurung).
   - *Verifikasi:* Pemindaian kode sumber (grep) menghasilkan 0 temuan em dash di seluruh folder `src/`.

2. **[PERF-01] Optimasi N+1 Query Loop Serial pada Katalog Kegiatan & Profil**
   - *Tindakan:* Menambahkan server actions batch `getUserRegisteredEventIds` dan `getUserRegistrationHistory` di `src/lib/actions/vihara-actions.ts`. Menggantikan pemanggilan serial `for...of getRegistrationsForEvent` yang sebelumnya memicu 20+ request beruntun.
   - *Hasil:* Waktu respon katalog kegiatan dan halaman profil turun drastis, rendering menjadi instan dan ringan.

3. **[R-38] Penghapusan Hardcoded ID Umat `p2` pada Katalog Publik**
   - *Tindakan:* Menghapus simulasi ID akun statis pada `src/app/(umat)/kegiatan/page.tsx`. Pendaftaran kini tersinkronisasi langsung dengan ID umat aktif dari sesi pengguna atau meminta pemilihan profil riil di menu profil.

4. **[R-25 / R-34] Penyesuaian Rasio Kontras WCAG AA**
   - *Tindakan:* Memperbaiki variabel CSS dan palet warna di `src/app/globals.css`, layout umat, dan layout admin. Teks gelap di atas latar gelap diganti dengan token kontras tinggi (`text-slate-100`, `text-amber-300`, `text-purple-200`) yang memenuhi rasio kontras minimal 4.5:1.

5. **[R-32] Aksesibilitas Indikator Fokus Keyboard**
   - *Tindakan:* Menambahkan utilitas global `:focus-visible` di `src/app/globals.css`, tombol `ThemeToggle`, `SearchableUmatSelect`, dan tombol switcher portal login. Pengguna keyboard dapat bernavigasi menggunakan Tab dengan cincin fokus yang jelas.

6. **[R-26 / R-32] Penanganan Tombol Escape pada Seluruh Modal Dialog**
   - *Tindakan:* Menambahkan event listener `Escape` pada `confirm-modal.tsx`, modal lupa password di `login/page.tsx`, dan dropdown pencarian `SearchableUmatSelect.tsx`.

### Kelompok 2: Prioritas MENENGAH (Purpose-Gate & Optimasi Rendering)

7. **[R-01] Rasionalisasi Gradien Ungu-Emas (`gradient-mnsbdi`)**
   - *Tindakan:* Menghilangkan penempelan gradien pelangi/monoton di semua kartu, tab, dan tombol. Menggantinya dengan latar solid berhierarki: aksen emas hanya untuk status penting dan tombol tindakan primer, sementara elemen penunjang menggunakan latar netral bersahaja.

8. **[R-04] Pembersihan Emoji Dekoratif Mentah**
   - *Tindakan:* Menghapus emoji dekoratif acak (`🪷`, `📍`, `✏️`, `👤`, `🔑`, `⏳`, `✉️`, `✨`, `📊`, `💸`) dari tata letak beranda, sidebar admin, form login, tanda terima donasi, modal RAB, dan master data umat. Digantikan dengan ikon vektor Lucide kontekstual dan tipografi rapi.

9. **[R-09] Penghapusan Eyebrow Capsule Badge Melayang**
   - *Tindakan:* Menghapus badge kapsul oval berulang di atas judul H1 beranda dan katalog kegiatan. Judul kini langsung mengomunikasikan inti layanan tanpa pengulangan klise.

10. **[R-19] Penghapusan Animasi Berulang Tak Berhenti (`animate-pulse`)**
    - *Tindakan:* Menghapus kelas `animate-pulse` tak henti pada kalender admin (`src/app/(admin)/calendar/page.tsx`), kalender umat (`src/app/(umat)/kegiatan/kalender/page.tsx`), dan hero section beranda. Mengurangi beban komposit GPU.

11. **[R-10 / PERF-02] Penurunan Tumpukan Backdrop Blur Berat**
    - *Tindakan:* Mengganti tumpukan ganda `backdrop-blur-md` pada toast notification, modal, navbar, dan kartu landing dengan latar belakang berbobot opacity solid (`bg-white/95 dark:bg-[#13092b]/95`). Rendering halaman di perangkat seluler menjadi jauh lebih mulus.

12. **[R-14] Diferensiasi Kartu Fitur Seragam Beranda**
    - *Tindakan:* Menata ulang 3 kartu fitur identik pada `src/app/page.tsx` menjadi pilar layanan terstruktur: Jadwal Puja Bhakti, Dana Paramita (Rekening Resmi), dan Layanan Umat & HAN.

13. **[R-08] Penghapusan Panah Penunjuk Dekoratif (`ArrowRight`) pada CTA**
    - *Tindakan:* Menghapus panah dekoratif acak pada tombol CTA utama beranda. Label tombol kini langsung, lugas, dan jelas tujuannya.

14. **[PERF-03] Peniadaan Beban Font Ekstra `Geist_Mono`**
    - *Tindakan:* Menghapus impor font Google `Geist_Mono` pada `src/app/layout.tsx`. Hanya memuat font `Geist` sans-serif esensial dengan konfigurasi `display: swap`.

15. **[PERF-04] Optimalisasi Komponen Manajemen Umat & HAN**
    - *Tindakan:* Memastikan memoization `useMemo` aktif untuk penyaringan data umat, membersihkan markup emoji, dan menjaga pagination tetap responsif pada 25 data per halaman.

## Addendum: Optimasi Latensi 0ms (Optimistic UI) & Respons Tombol Taktil

Menindaklanjuti pengujian interaksi pengguna, dilakukan peningkatan performa responsivitas aksi tombol di seluruh aplikasi:
1. **0ms Optimistic UI:**
   - Aksi presensi kehadiran (`Tandai Hadir` / `Batalkan Presensi`), pelunasan (`Tandai Lunas` / `Batalkan Lunas`), biaya ekstra, dan pembatalan pendaftaran di [EventPresensiTab.tsx](file:///d:/Vihara/src/components/events/EventPresensiTab.tsx) dan [page.tsx](file:///d:/Vihara/src/app/(admin)/events/[eventId]/page.tsx) kini memperbarui state visual seketika (**0 milidetik**) sebelum sinkronisasi latar belakang selesai.
   - Penyesuaian stok inventaris (`+` dan `-`) dan status event selesai/publikasi kini juga menggunakan pembaruan optimistik instan.
2. **Eliminasi Delay Native Dialog:**
   - Menghilangkan dialog popup bawaan peramban (`window.confirm()`) yang membekukan thread peramban dan menggantinya dengan konfirmasi inline dua langkah cepat.
3. **Mikro-Interaksi Taktil Global:**
   - Menambahkan efek tekan mikro fisik (`active:scale-[0.972]` dan transisi 80ms) di [globals.css](file:///d:/Vihara/src/app/globals.css) sehingga setiap tombol di seluruh website langsung merespons sentuhan/klik pengguna tanpa rasa delay atau mengambang.
4. **Desain Tab Segmented Modern:**
   - Mengganti garis bawah tab yang kaku menjadi wadah tab segmented pill yang kontras, rapi, dan instan berpindah saat ditekan di seluruh portal Admin dan Umat.
